# Telegram TikTok Downloader Bot

Bot Telegram simple untuk download:
- TikTok video
- TikTok slideshow
- TikTok story publik

Deploy cocok untuk Vercel webhook.

## Install

```bash
npm install
```

## Jalankan local

```bash
npm run dev
```

## Deploy

```bash
npx vercel
```

Lalu set webhook:

```txt
https://api.telegram.org/botTOKENKAMU/setWebhook?url=https://DOMAINKAMU.vercel.app/api/webhook
```
